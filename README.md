# Student Performance Data Preprocessing

## Project Overview
This project was completed as part of the YuvaIntern AI Pioneers Machine Learning Internship, Week 1 task.

## Objectives
- Load and inspect a real-world dataset using Pandas.
- Check missing values and duplicate records.
- Encode categorical variables.
- Normalize numerical features.
- Perform exploratory data analysis (EDA).

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Dataset
Student Performance dataset from the UCI Machine Learning Repository.

Source: https://archive.ics.uci.edu/dataset/320/student+performance

## Outputs
- Preprocessed CSV dataset
- Final grade distribution graph
- Average grade by study-time category graph

## How to Run
Install the required libraries:

```bash
python -m pip install pandas scikit-learn matplotlib
```

Run the project:

```bash
python week1_preprocessing.py
```

## Findings
The Mathematics dataset contains 395 records and 33 original columns. Initial inspection found no missing values or duplicate rows. Categorical encoding and numerical feature normalization were applied before visualization.
